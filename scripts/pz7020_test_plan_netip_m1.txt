Command surface:
  net ip <a.b.c.d> <seconds>   -> kernel::net_ip::serve()  (arm + bm-net)
    brings up smoltcp Interface (EthernetAddress = BOARD_MAC, static IPv4/24),
    then polls iface for <seconds>. ARP + ICMP echo answered automatically by
    smoltcp during the window.

Bare-metal ARP + IPv4 + ICMP over GEM0 via smoltcp is real and proven.
