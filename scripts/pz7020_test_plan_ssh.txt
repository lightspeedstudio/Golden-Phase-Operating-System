CORROBORATION: host received the board shell's real "system status" output over the

WHAT THIS PROVES (end to end, on bare metal, no OS):
  TCP (smoltcp) -> SSH transport + key exchange (x25519) -> ed25519 host key
  -> ed25519 public-key userauth -> session channel -> exec bridged into the board
  shell (via ShellAction::RunSshServer from the boot loop) -> encrypted stdout back.

NOTES / follow-ups:
  - KEX negotiated x25519 (client warned "not post-quantum"); sunset also offers ML-KEM
    hybrid — client picked classical. Functionally complete for the milestone.
  - Host key regenerates per boot (SignKey::generate); clients use StrictHostKeyChecking=no.
    A stable seed-derived host key is a straightforward follow-up.
  - Entropy is proof-grade only (no PS TRNG); production needs a PL ring-oscillator TRNG
    fed into rng::reseed().
  - Interactive shell (pty) not offered yet — exec channel only (`ssh host "<cmd>"`).
