KairOS Build Size Report
========================
Date: 2026-07-07
Profile: release (optimized)
Platform: x86_64-pc-windows-msvc (hosted binaries)
Toolchain: Rust 2021 edition, kairos v0.1.0

Executive Summary
-----------------
KairOS ships as a compact research operating system: roughly 1.0 MB of Rust source,
32 integration test crates, and release hosted binaries under 5 MB each on Windows.
The library artifact (libkairos.rlib) is ~10.5 MB because it embeds the full kernel,
userland, networking, security, and optional SSH stack for linking into multiple binaries.

Release Binaries (Windows x86_64)
---------------------------------
  kairos_host.exe     4,356,096 bytes  (4.15 MB)  — interactive hosted runtime + shell
  kairos_ssh.exe      4,830,208 bytes  (4.61 MB)  — hosted runtime + SSH operator server

Interpretation
--------------
- Hosted operator console fits in ~4–5 MB per binary — suitable for lab, QEMU-sidecar,
  and edge prototyping without container overhead.
- SSH server adds ~474 KB over kairos_host (Ed25519 host keys, russh, tokio runtime).
- The 1 MB source footprint reflects a deliberately minimal but complete phase-kernel OS
  with audit, networking, AI bridge, and full engineering terminal — not a Linux-scale tree.
- For publication: cite "sub-5 MB hosted operator binaries" and "~1.2 MB Rust source (src+tests)".
