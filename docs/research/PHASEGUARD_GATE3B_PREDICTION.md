## 1. Motivation

Gate 3 left one honest blind spot: a **plausible finite** falsification of the
squeeze coordinate `s` preserves `A·B=√α` and is invisible to a product-only
witness. Gate 3B adds a second, **independent** test — not manifold *membership*
but manifold *location*:

```
A(s)·B(s) = √α                confirms the point is ON the product manifold   (Gate 3)
s_observed = s_expected       confirms the point is at the RIGHT place on it   (Gate 3B)
```

## 2. The causal predictor (no peeking, no lookup)

The expected squeeze is a closed-form function of the **dual-clock position only**
(the tick / `sequence`), with **no free parameters**:

```
s_expected(tick) = s* · cos( 2π · tick / SECTOR_COUNT )
```

where `s* = ¼·ln(y²_outer/y²_inner) = 1.4693…` is the canonical squeeze
coordinate from Gate 1 (fixed by α, φ). Key honesty properties, each test-guarded:

- **Prior information only.** `predict_squeeze` reads the tick, never the
  observation's `s`. Test `prediction_uses_only_prior_information` feeds it a
  tampered observation and confirms it still returns the *clean* expected value.
- **No lookup table.** It is one formula applied uniformly, not a stored set of
  valid answers for the test cases.
- **Generalizes.** Test `zero_false_positives_on_unseen_valid_traces` runs 48
  valid traces (starts {0,1,3,7,10,23,100,999} × lengths {1,2,5,13,40,97}) the
  predictor was never built against — **zero false positives**.

## 4. Honest boundary — what 10/10 does and does NOT mean

- The 10/10 holds **within a model where the squeeze coordinate is generated by
  the clock-bound law** the predictor also uses. This is not circular (the
  predictor never sees the value and generalizes to unseen ticks with zero FP),
  but it **is contingent on that law being physically real.**
- **Open question for Gate 4:** does the *live kernel's* squeeze coordinate
  actually obey a clock-derived law like `s*·cos(θ(tick))`? If yes, the witness
  transfers and the blind spot is genuinely closed on hardware. If the kernel's
  squeeze is driven differently, the predictor must be re-derived from the real
  StateClock geometry (`phi`, `sector_id`, `epsilon`, `x=2cos(φ/5)`) before any
  10/10 claim can be made on-device. **No hardware/kernel claim is made here.**
- The tested adversary falsifies a **single** field (`s`) leaving the tick
  intact. A fully-coordinated forgery that simultaneously satisfies sequence,
  sector, branch, product, **and** the clock-prediction is a stronger adversary
  not evaluated here.

## 5. Verdict

Gate 3B converts the honest 9/10 into an honest **10/10 with zero false
positives** by adding a causal, parameter-free, clock-derived location test —
demonstrating that PhaseGuard can, in principle, uniquely determine squeeze
location, not just manifold membership. The result is real but **model-bound**;
its transfer to the kernel is exactly what Gate 4 must measure.
