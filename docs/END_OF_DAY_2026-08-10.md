## 1. The USB wall — root cause (a humbling one)

Yesterday U1 was blocked: the USB3320 PHY VID read `0x0000` and every control transfer
`XactErr`'d. After a full diagnostic pass (ULPI viewport instrumentation, PHY-reset pulse,
side-channel dumps), the actual cause was tiny:

> **The ULPI MIO TRI map had CLK and DATA5 swapped.** CLK is **MIO36** (`0x1205`, input);
> DATA5 is **MIO37** (`0x1204`, output). v1–v9 put `0x1205` on MIO37 instead of MIO36, which
> killed ULPI register access.

Fix: swap two entries in `USB0_MIO` (`usb.rs`). Immediately: **PHY VID=0x0424**, scratch
round-trips, high-speed connect, and an 8-byte `GET_DESCRIPTOR`. Commit `54fd5c0`.
Lesson recorded: a one-entry mux transcription error is invisible to code review — only
hardware proof catches it.

## 2. Phase 2 — USB U1 enumeration (PROVEN)

Built the standard-request chain on the now-working transfer engine: `GET_DESCRIPTOR(device)`
→ `SET_ADDRESS(1)` → `GET_DESCRIPTOR(config)` → `SET_CONFIGURATION` → parse the HID interface.

```
usb1: 1a2c:7fff class=HID addr=1 cfg=1 ep0=64 full-speed int-in=0x83 maxpkt=64 interval=1
usb: phase lifecycle -> powered -> connected -> reset -> addressed -> configured
```

`usb.rs`: `UsbDevice`, `enumerate()`, `list()`, `set_address`/config-descriptor/`set_configuration`
+ `parse_config`. New shell command `usb list` (`Command::UsbList`) drives `DomainId::Usb` to
`configured`. Commit `b4b7d76`.

## 3. Phase 3 — USB U2 HID keyboard input (PROVEN)

`SET_PROTOCOL(boot)` + an interrupt-IN poll (single IN qTD on the async schedule — no periodic
frame list needed for one HID device). Real keystrokes captured:

```
HID int-in endpoints found: 3
    ep=0x81 iface=0 proto=1  <- polling   (boot keyboard)
  report: 00 00 08 1c 00 00 00 00   (e, y, ...)
usb keys: 24 report(s) captured
```

A composite-device bug surfaced and was fixed: `parse_config` now records **all** HID
interrupt-IN endpoints and **prefers the boot-keyboard interface** (was polling iface2/ep0x83;
keys are on iface0/ep0x81). New `usb keys` diagnostic. Brain → `hid_ready`. Commit `a239f31`.
