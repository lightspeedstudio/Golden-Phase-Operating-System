# System 2 — working Zynq-7000 boot-image reference

Parsed from the System 1 gold fixture **before** any owned packer was written. Independent parse matches `src/board/zynq_bootimg.rs` (`loader_bitstream_app` / `parse_iht` / `parse_partition`). No replacement format was invented.

**Fixture.** `fpga/zynq/release/PZ7020_G1P_PATH1_G64/BOOT.BIN`  
SHA-256 `7da748547d5016191643ddc4df555a8cf02c1d8adee3235f1dde766166ea0b85`  
6114836 bytes. System 1 lock commit `d5ffeb1ae9022d16d2a2edff504dcc93a12cb72c`. Do not edit this file. It is a permanent parse regression fixture, not an owned packer output.

**Bootgen.** This `BOOT.BIN` is the historical Bootgen product. System 2 does not run Bootgen. Bootgen is a comparison oracle only (this fixture).

**Parser vs packer.** The independent owned parser must accept this fixture. It must not call packer internals. Owned packer output is allowed to differ only as listed under Intentional differences.

## Boot header (UG585 Ch. 6, Zynq-7000)

Little-endian u32. Checksum at `0x048` is `~sum` of words **`0x020` through `0x044` inclusive**. Verified on this fixture: stored `0xFC155718`.

| Offset | Field | Gold value | Notes |
| --- | --- | --- | --- |
| 0x000–0x01C | ARM vectors | `0xEAFFFFFE` × 8 | Width-detection prefix |
| 0x020 | Width detection | `0xAA995566` | UG585 |
| 0x024 | Image identification | `0x584C4E58` (`XLNX`) | Same check as `zynq_bootimg::IMAGE_IDENT_XLNX` |
| 0x028 | Encryption | `0x00000000` | none |
| 0x02C | FSBL / image attributes | `0x01010000` | Bootgen field; reproduce |
| **0x030** | **Source Offset** | **`0x00001700` (5888)** | **Byte offset of Stage 1 payload. Not payload data. Not the length.** |
| 0x034 | Length of Image | `0x0001F714` (128788) | Stage 1 byte length |
| 0x038 | FSBL load address | `0x00000000` | OCM; BootROM destination |
| 0x03C | Start of execution | `0x00000000` | OCM |
| 0x040 | Total FSBL length | `0x0001F714` | equals 0x034 (unencrypted) |
| 0x044 | QSPI config | `0x00000001` | |
| 0x048 | Header checksum | `0xFC155718` | |
| 0x098 | Image header table pointer | `0x000008C0` | **byte** offset |
| 0x09C | Partition header pointer | `0x00000C80` | **byte** offset |
| **0x0A0** | Register-init first word | **`0xFFFFFFFF`** | Unused address. 256 pairs `(0xFFFFFFFF, 0x00000000)` at `0x0A0..0x8A0`, then `0x8A0..0x8C0` filled `0xFFFFFFFF`. |

`0x030 + 0x034 = 0x20E14 <= file_len`. `0x030` equals partition 0 `data_off`.

Matches `zynq_bootimg` (`IHT_OFFSET = 0x8C0`, version high-half `0x0102`).

| Offset | Field | Gold value |

## Partition headers at `0xC80` (16 words, checksum `~sum(words[0..15])`)

Independent parse with the `zynq_bootimg.rs` algorithm: all three checksums match; `loader_bitstream_app` succeeds.

| | P0 Stage 1 | P1 PL | P2 Utility |
| --- | --- | --- | --- |
| Header offset | `0xC80` | `0xCC0` | `0xD00` |
| enc/data/total words | `0x7DC5` | `0xF6EC0` | `0x76135` |
| Byte length | 128788 (`0x1F714`) | 4045568 (`0x3DBB00`) | 1934548 (`0x1D84D4`) |
| Load address | `0x00000000` | `0x00000000` | **`0x00100000`** |
| Exec address | `0x00000000` | `0x00000000` | **`0x00100060`** |
| Data offset (words) | `0x5C0` | `0x8390` | `0xFF250` |
| **Data offset (bytes)** | **`0x1700`** | **`0x20E40`** | **`0x3FC940`** |
| Attributes | `0x10` PS | `0x20` PL | `0x10` PS |
| Sections | 1 | 1 | 1 |
| Image header words | `0x240` | `0x250` | `0x260` |
| End offset | `0x20E14` | `0x3FC940` | `0x5D4E14` (= file_len) |
| Align 64 | 0 | 0 | 0 |
| Align 512 | **256** | **64** | **320** |

Empty P3 header at `0xD40` is all-zero plus checksum `0xFFFFFFFF` (not a live partition; IHT count is 3).

P0 payload at `0x1700` is Bootgen-packaged Stage 1 (ARM vectors), not a raw ELF. P1 length is the bitstream partition (`.bit` including header). P2 length equals Utility `PT_LOAD` FileSiz.

## Alignment of the working image

Gold later payloads are **64-byte** aligned, **not** 512-byte aligned. The owned parser **must still parse this fixture**. 512-byte alignment of partitions after Stage 1 is an owned-packer correction (SD block / ADMA2), not a reason to reject gold.

## Intentional differences (owned packer vs this fixture)

Each row has a host test in `zynq_stage1/owned`.

## Independent parse vs `zynq_bootimg.rs`

On this fixture both agree:

- ident `XLNX` at `0x24`
- IHT version `0x01020000`, count 3, PH at `0xC80`
- P0 PS `load=0` (loader), P1 PL, P2 PS `load=0x00100000` `exec=0x00100060`
- Not encrypted, no vendor RSA attribute

`zynq_bootimg.rs` is not modified (System 1 hash `c96b4b13…` preserved). Owned parser is a separate module and does not `use` the packer.

## parse_all / file length

Partition `data_off + byte_len` is checked against **`file_len`**, not against a 16 KiB header window. Passing only the header bytes with the real `BOOT.BIN` length must succeed for header fields; payload slices require the full file.
