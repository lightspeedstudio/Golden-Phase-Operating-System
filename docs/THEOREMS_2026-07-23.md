## Theorem 1 — Coherence
For any word of any length over {Φ0..Φ3}, **every** parenthesization evaluates
into a single reflection orbit {v, 3−v}. A computation's value is well-defined
up to exactly one parity bit.
*Proof:* finite 16-case check (compose respects reflection orbits: for all a,b
the set {a∘b, a∘ρb, ρa∘b, ρa∘ρb} lies in one orbit — PASS) + the quotient is
associative (Theorem 2) + induction on word length.
*Verified exhaustively* for word lengths 3–7 (21,824 words, all
parenthesizations, 0 violations).

## Theorem 2 — Structure
The reflection orbits are O={Φ0,Φ3}, I={Φ1,Φ2}. Compose descends to the
orbits, where it is exactly **Z₂ (XOR)**. The quotient map is the existing
`threshold_energy` partition. GPL = Z₂ twisted by reflection; all
non-associativity lives in the fiber. (Same structural pattern as twisted
group algebras, e.g. octonions over Z₂³.)
